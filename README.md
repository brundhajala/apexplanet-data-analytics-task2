# ApexPlanet Data Analytics - Task 2

## Exploratory Data Analysis and Business Intelligence

This project analyzes the official ApexPlanet cleaned sales dataset using Python, SQL, and data visualization.

## Dataset Summary

- Total orders: 992
- Total sales: INR 138,104,311.37
- Average order value: INR 139,218.06

## Key Insights

- Electronics is the highest sales category.
- Laptop is the highest-selling product.
- Patna is the top city by sales.
- The 36-45 age group generates the highest sales.
- March 2025 recorded the highest monthly sales.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- SQLite
- VS Code
